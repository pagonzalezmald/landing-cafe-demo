# AMBLE COFFEE CO. — Landing Page Demo

A landing page template built as a portfolio piece for a specialty coffee shop: hero, a filterable menu (Coffee / Pastries / Seasonal), locations, and an order-ahead flow that's upfront about being a demo before any "order" step.

**Live demo:** https://pagonzalezmald.github.io/landing-cafe-demo/

Built by [Pablo Gonzalez](https://github.com/pagonzalezmald) — more examples in [pg_portfolio](https://github.com/pagonzalezmald/pg_portfolio).

## Stack

Vanilla HTML, CSS, and JavaScript — no build step, designed to deploy directly to GitHub Pages.

## Note

This is a demo/template. The brand name ("AMBLE"), menu, locations, and reviews are fictional, created solely to illustrate the page structure — they do not correspond to a real café. The "Order Ahead" flow intentionally does not place a real order or connect to a POS system.
